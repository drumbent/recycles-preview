re-Cycles website redesign — Version 4.1 (demonstration)

This is a static design prototype, NOT the official re-Cycles website and NOT yet a WordPress implementation.
All operating hours, policies, service descriptions and contact details should be reviewed by the organization before launch.
News cards are examples. Instagram account URL has not been confirmed.

LOCAL PREVIEW
Open index.html in a browser. No installation required.

GITHUB PAGES
1. Create a NEW GitHub repository, e.g. recycles-preview. Do not change the live site's hosting or DNS.
2. Upload the CONTENTS of this folder to the repository root (index.html must be at the root).
3. Commit changes.
4. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub to publish and use the Pages URL shown in Settings > Pages.
6. Share the link with reviewers.

CAUTION
A public GitHub Pages preview can be discovered or shared beyond the intended audience. Avoid including private data.
This package intentionally excludes the original site's archived directory.
